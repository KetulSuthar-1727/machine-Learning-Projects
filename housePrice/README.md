# Project Details 

🏠 House Price Prediction using Machine Learning

A simple machine learning project that predicts house prices based on various factors like number of bedrooms, bathrooms, living area, condition, and grade of the house.

🧩 Project Overview

This project demonstrates a complete ML workflow:

Data loading and cleaning using Pandas

Data visualization with Matplotlib

Model building with Linear Regression from Scikit-learn

Model evaluation using R², MAE, MSE, and RMSE

🧰 Technologies Used

Python 🐍

Pandas

NumPy

Matplotlib

Scikit-learn

📊 Dataset

The dataset contains details about houses, including:

Number of bedrooms & bathrooms

Living area & lot area

Condition, grade, and year built

Renovation year, postal code, and price

🚀 How It Works

The data is cleaned (handling missing values, replacing 0s, etc.)

Features (like area, grade, and age) are used to train a Linear Regression model

The trained model predicts house prices for new input data
